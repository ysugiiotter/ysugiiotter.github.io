animal-zukan-analytics

YouTubeチャンネル「毎日30秒アニマル図鑑」の運営者が、自分のチャンネルのためだけに使う個人用ツールです。

このツールでできること

  • 運営者自身のチャンネルの動画一覧と、YouTubeアナリティクスの数値(再生回数・視聴維持率など)を読み取り、改善のためのレポートを作成します。
  • 運営者自身が制作した動画を、運営者自身のチャンネルに予約投稿します。

このツールは一般には公開・配布しておらず、運営者以外のユーザーは利用できません。YouTube API Services を利用しています。

About (English)

animal-zukan-analytics is a private, single-user tool operated by the owner of the YouTube channel "毎日30秒アニマル図鑑" (Everyday 30-Second Animal Encyclopedia). It reads the owner's own channel analytics to produce improvement reports, and schedules uploads of videos the owner created to the owner's own channel. It is not distributed or offered to any other user. This tool uses YouTube API Services.
