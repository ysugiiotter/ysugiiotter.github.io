プライバシーポリシー

対象: animal-zukan-analytics(以下「本ツール」) / 最終更新日: 2026年10月10日

1. 本ツールについて

本ツールは、YouTubeチャンネル「毎日30秒アニマル図鑑」の運営者(以下「運営者」)が、自分のチャンネルの分析と動画の予約投稿のためだけに使う個人用ツールです。運営者以外のユーザーは利用できません。

本ツールは YouTube API Services を利用しています。本ツールを利用することにより、利用者は YouTube利用規約 に同意したものとみなされます。YouTube API Services を通じて取得される情報の取り扱いについては、Googleのプライバシーポリシー も適用されます。

2. アクセス・収集する情報

本ツールは、利用者(運営者)がGoogleアカウントで許可した範囲で、YouTube API Services から次の情報にアクセスします。

  • 運営者のチャンネルの基本情報(チャンネル名、登録者数、動画数)
  • 運営者のチャンネルの動画情報(タイトル、公開日時、長さ、公開状態)
  • 運営者のチャンネルのYouTubeアナリティクスの集計値(再生回数、視聴時間、視聴維持率、登録者の増減、流入元など)
  • 動画の予約投稿のために、運営者が用意した動画ファイルとタイトル・説明文・タグ
  • 競合調査のための、YouTube上の公開動画の公開情報(タイトル、再生回数、長さ、チャンネル登録者数)

本ツールは、運営者以外の個人のアカウント情報や、視聴者個人を特定できる情報を収集しません。

3. 情報の利用目的

取得した情報は、運営者自身のチャンネルの改善(レポート作成、動画づくりの参考)と、運営者自身の動画の予約投稿のためだけに利用します。広告、販売、第三者への提供には利用しません。

4. 保存と共有

  • 取得した情報は、運営者のパソコン内にのみ保存します。外部のサーバーには送信・保存しません。
  • 認証情報(アクセストークン)は運営者のパソコン内に保存し、第三者と共有しません。
  • 取得した情報を第三者に開示・共有・販売することはありません。
  • 本ツールはCookieや、閲覧履歴を記録する仕組みを使用しません。

5. 保存期間と削除

YouTube API Services から取得した情報は、分析に必要な期間のみ保存し、YouTube API Services の開発者ポリシーに従って、最長30日ごとに再取得・更新するか、不要になったものは削除します。運営者はいつでも、パソコン内の保存データを削除できます。

6. アクセス許可の取り消し

本ツールへのアクセス許可は、Googleアカウントのセキュリティ設定ページ からいつでも取り消すことができます。

7. 変更

本ポリシーを変更する場合は、このページで最終更新日とともにお知らせします。

Privacy Policy (English)

Applies to: animal-zukan-analytics ("the Tool") / Last updated: October 10, 2026

The Tool is a private, single-user tool used only by the operator of the YouTube channel "毎日30秒アニマル図鑑" to analyze the operator's own channel and to schedule uploads of the operator's own videos. No other users can use it.

The Tool uses YouTube API Services. By using the Tool, users agree to be bound by the YouTube Terms of Service. The Google Privacy Policy also applies.

Information accessed: with the operator's authorization, the Tool accesses the operator's channel information, the operator's video information, aggregated YouTube Analytics metrics for the operator's channel, the video files and metadata the operator prepares for scheduled upload, and public information about public YouTube videos for trend research. The Tool does not collect personal information about any other person or about individual viewers.

Use: the information is used only to improve the operator's own channel and to schedule the operator's own uploads. It is not used for advertising, sold, or shared with third parties.

Storage and sharing: data and access tokens are stored only on the operator's own computer and are never sent to external servers or shared with third parties. The Tool does not use cookies.

Retention and deletion: data obtained from YouTube API Services is kept only as long as needed for analysis and is refreshed or deleted at least every 30 days in accordance with the YouTube API Services Developer Policies. The operator can delete stored data at any time.

Revoking access: access can be revoked at any time via the Google security settings page.
